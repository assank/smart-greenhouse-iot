# Умная теплица: готовый комплект

## Сайт и исходники

[Открыть сайт](https://assank.github.io/smart-greenhouse-iot/) · [Проект Wokwi](https://wokwi.com/projects/476959057155028993)

Сайт размещён на GitHub Pages и открывается независимо от Codex. Самостоятельная демонстрация работает сразу. Для режима ESP32 запустите Wokwi и нажмите «Подключить Wokwi» на сайте.

## Быстрый запуск

1. Откройте `index.html` в Chrome, Edge или Safari. Это интерактивная модель, которая работает и без интернета.
2. На Mac также можно дважды нажать `Запустить.command`: он откроет модель через локальный сервер. Терминал нужно оставить открытым во время демонстрации.
3. Переключайте «Жара», «Сухая почва», «Мало воды», «Темно днём», «Ночь», «Сбой датчика».
4. Вращайте модель мышью, приближайте колесом, выбирайте детали по подписям или из списка «Деталь модели».
5. Откройте `presentation.pptx` для выступления. Текст, таблицы и схемы можно редактировать.

## Работающий проект Wokwi

[Открыть готовую схему ESP32](https://wokwi.com/projects/476959057155028993)

Нажмите зелёную кнопку ▶. На бесплатном тарифе компиляция может ждать в очереди. Дождитесь запуска и подключения Wi-Fi.

В открытой модели нажмите «Подключить Wokwi». После появления надписи «ESP32 / Wokwi» модель показывает данные платы. Кнопки сценариев отправляют команды на ESP32, а состояния насоса, вентилятора и лампы берутся из его ответа. Ручные ползунки в этом режиме отключены.

«Читать датчики» возвращает ESP32 к показаниям компонентов Wokwi. В этом режиме можно менять температуру DHT22, потенциометр почвы, свет LDR и расстояние HC-SR04 непосредственно в Wokwi. Время приходит через NTP, часовой пояс UTC+5. До получения корректного времени досветка заблокирована.

«Вернуться в демо» переключает модель на самостоятельную JavaScript-логику. На физическое состояние уже запущенного Wokwi это не влияет.

Если соединение с ESP32 потеряно, модель помечает показания как устаревшие. Для защиты при плохом интернете используйте самостоятельную демонстрацию и скриншоты из `assets/`.

## Команды монитора порта

В Wokwi можно отправить текстовую команду, завершив её переводом строки:

| Команда | Назначение |
|---|---|
| `sensors` | Показания компонентов симулятора |
| `normal` | Нормальные условия |
| `hot` | 32 °C, вентиляция |
| `dry` | Почва 25 %, полив |
| `empty` | Вода 10 %, полив заблокирован |
| `dark` | День, свет 15 %, лампа включена |
| `night` | 23:00, свет 5 %, лампа выключена |
| `fault` | Некорректный сигнал уровня, полив заблокирован |

Последний выбранный режим сохраняется в NVS. Чтобы после демонстрации снова читать компоненты, отправьте `sensors`.

## Что внутри

- `index.html`: самостоятельная 3D-модель. Three.js, OrbitControls и MQTT-клиент включены в файл, CDN не нужен.
- `presentation.pptx`: восемь слайдов с пояснениями в заметках докладчика.
- `ЗАЩИТА.md`: последовательность показа, короткая речь и ответы на вопросы.
- `ТЕХНИЧЕСКИЙ_ОТЧЁТ.md`: описание именно реализованной версии.
- `wokwi/sketch.ino`: полный код ESP32, включая логику управления.
- `wokwi/diagram.json`: соединения компонентов.
- `wokwi/libraries.txt`: библиотеки Arduino.
- `assets/`: концептуальная иллюстрация и реальные скриншоты.

## Границы версии

Это учебный симуляционный прототип. Насос, вентилятор и лампа в Wokwi представлены реле и индикаторами, а движение воды и воздуха на модели служит визуальным пояснением. Шкалы влажности почвы и освещённости относительные. Модель не рассчитывает рост растений, теплообмен или впитывание воды. Переключение сценария намеренно начинает новый тест с исходными состояниями.

Интернет вещей реализован через Wi-Fi и двусторонний MQTT. Telegram, HTTPS/TLS на ESP32 и изменение порогов с сохранением в NVS в эту версию не входят. В исходном отчёте они были заявлены, поэтому для сдачи используйте обновлённый отчёт из этого комплекта.

MQTT-связь использует общий публичный брокер HiveMQ: ESP32 подключается к TCP-порту 1883, браузер — к защищённому WebSocket-порту 8884. Топики `smartgreenhouse/sg-8d37a9e6/state` и `smartgreenhouse/sg-8d37a9e6/command`. Это канал для демонстрационных данных. Если несколько человек запускают копии одновременно, задайте каждой копии свой идентификатор и топики в прошивке и модели.

## Разработка

Исходный интерфейс: `src/shell.html`, поведение и 3D-модель: `src/app.js`, логика: `src/controller.js`. Полная прошивка и схема лежат в `wokwi/`.

Собрать автономный `index.html`:

```sh
python3 tools/build.py
```

Проверить контроллер:

```sh
node tests/test_controller.mjs
mkdir -p .build
c++ -std=c++17 tests/test_controller.cpp -o .build/test_controller
.build/test_controller
```

GitHub Pages публикует корень ветки `main`. После изменения исходников пересоберите `index.html` и сохраните оба изменения в Git.
